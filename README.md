# <img width="64" height="64" alt="psaroeditor" src="https://github.com/user-attachments/assets/9c2d8225-de97-43d7-a49a-036943cb3784" /> Shufflingway

Lightweight FFTCG client and fan project.

Includes a deck manager, full card browser, game board and CPU opponent.

Links to rules and guides are found in the Help menu.

<img width="2456" height="1380" alt="Deck Manager" src="https://github.com/user-attachments/assets/87c0fcc9-7fec-4128-a8c5-b26aa17f0c3e" />
<img width="2456" height="1384" alt="Game Board" src="https://github.com/user-attachments/assets/be915f5b-1443-40fb-ae8c-41c745a2adc8" />

Shufflingway allows you to play against a CPU or a friend with the application facilitating the flow of the game, tracking the game state and resolving card interactions.

Current card coverage: **100%**

# Installation Guide

Use the 'Releases' section on the right to download the latest version.

* .msi: Windows Installer
* .dmg: MacOS 13+
* .deb: Linux

Once the application has been installed, you can update to any new releases from "Check for Updates..." in the Help menu.

# Quick Start Guide

* Open the Card Browser to initiate fetching card data from the official API.  
* After this completes, create a deck in the Deck Manager. Various preconstructed decks can be loaded via the button at the top.
* Once a 50-card deck has been created, you can jump into match against a friend or the CPU!
