# <img width="64" height="62" alt="shufflingway icon" src="https://github.com/user-attachments/assets/16c919c4-2701-4751-b325-303133e9ff52" /> Shufflingway

Lightweight FFTCG client and fan project.

Includes a deck manager, full card browser, game board and CPU opponent.

Links to rules and guides are found in the Help menu.

Shufflingway allows you to play against a CPU or a friend with the application facilitating the flow of the game, tracking the game state and resolving card interactions.

Current card coverage: **100%**

# Installation Guide
![Latest release](https://img.shields.io/github/v/release/RockefellerA/Shufflingway)

Download the installer for your platform:

* [Windows Installer (.msi)](https://github.com/RockefellerA/Shufflingway/releases/latest/download/Shufflingway-Windows.msi): Windows
* [Mac Installer (.pkg)](https://github.com/RockefellerA/Shufflingway/releases/latest/download/Shufflingway-macOS.pkg): macOS 13+
* [Linux Installer (.deb)](https://github.com/RockefellerA/Shufflingway/releases/latest/download/Shufflingway-Linux-amd64.deb): Debian/Ubuntu

Release notes and earlier versions are in the [Releases](https://github.com/RockefellerA/Shufflingway/releases) section.

Once the application has been installed, you can update to any new releases from "Check for Updates..." in the Help menu.

# Quick Start Guide

* Open the Card Browser to initiate fetching card data from the official API.  
* After this completes, create a deck in the Deck Manager. Various preconstructed decks can be loaded via the button at the top.
* Once a 50-card deck has been created, you can jump into match against a friend or the CPU!
